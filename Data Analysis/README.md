# Demon Slayer Data Analysis

This project performs basic data analysis on Demon Slayer character data using Python.

## Tasks Performed
- Loaded CSV data using Pandas
- Calculated basic statistics (average age, summary)
- Created visualizations using Matplotlib and Seaborn:
  - Bar chart
  - Scatter plot
  - Heatmap

## Files Included
- `demon_slayer_data_analysis.py` – Main Python script
- `characters.csv` – Dataset used for analysis
- `character_distribution_analysis.png` – Output visualization
- `HOW_TO_RUN_Demon_Slayer_Project.pdf` – Step-by-step execution guide

## How to Run
```bash
python demon_slayer_data_analysis.py
