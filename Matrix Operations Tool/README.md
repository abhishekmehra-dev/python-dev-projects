# Matrix Operations Using NumPy

This project performs basic matrix operations using Python and the NumPy library through a menu-driven program.

## Tasks Performed
- Accepted matrix input from the user
- Performed matrix addition
- Performed matrix subtraction
- Performed matrix multiplication
- Calculated matrix transpose
- Calculated matrix determinant

## Files Included
- `matrix_operations.py` – Main Python script containing all matrix operations

## How to Run
```bash
python matrix_tool.py
Requirements

• Python 3
• NumPy
